# Shiori content

Downloadable content for the Shiori app, served by GitHub Pages at
https://ahuix.github.io/shiori-content/

- `content/index.json` — story list, dictionary and grammar (the app checks `builtAt` for updates)
- `content/episodes/<story>/<n>.json` — episodes, downloaded when opened
- `audio/` — recorded voices (MP3 sprites + `index.json`)
- `sound/` — background ambience and music loops

Generated by `scripts/publish-content.sh` in the `shiori` repository — don't edit by hand.
